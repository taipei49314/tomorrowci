# Example reports

HTML reports for fixtures are generated by:

```
cargo test -p tomorrowci-runner --test m1_m2_pipeline
# and when Docker daemon is available:
cargo run -p tomorrowci-cli -- scan fixtures/python-runtime-break
```

Scripted pipeline tests write evidence under the fixture tempdir (ephemeral).
Docker-backed evidence appears under .tomorrowci/runs/<run-id>/report.html.
